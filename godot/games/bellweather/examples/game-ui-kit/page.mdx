Every 2D game needs the same few pieces of interface: a panel for dialogue and menus, a button in its
four states, and a set of system icons. Made by hand, each one has to be cut so it
stretches without smearing its corners, lined up so the pressed state does not jump, and kept in the
game's style. FX Games makes each sheet as a short chain in the game's graph. The image model paints
over a geometry template, with the game's cover as its style reference. A local gate then measures
what came back: where the corners end, where text can sit and in which colour, where each icon
is. A reviewer that did not draw the sheet judges its style. The measurements travel with the
sheet, so an engine lays it out without guessing.

## Where it works

<Scope>
  <Works>Any 2D game's standard screens: dialogue, menus, pause, settings</Works>
  <Works>One style picture, such as the game's cover or a style plate</Works>
  <Works>Panels and buttons that stretch to any size without distorting their corners</Works>
  <Works>A short direction per sheet, in plain words</Works>
  <Limit>Text: the sheets carry none, so labels are set in the engine</Limit>
  <Limit>Item icons for a game's own things: these 16 are system icons</Limit>
  <Limit>Animated interface</Limit>
  <Limit>A strictly flat, vector look: the model tends to add shading, and the reviewer flags it</Limit>
  <Tip>The reviewer's verdict is recorded, not enforced. Here it accepted the panel and the buttons, and rejected the icons for glossy shading where flat colour was asked for.</Tip>
  <Tip>The gate is what stops a run. A drawing whose corners run into the edge bands is refused and drawn again.</Tip>
  <Tip>The gate also picks the text colour for each surface from its measured contrast.</Tip>
</Scope>

## What goes wrong by hand

<Guards>
  <Guard node="ui-panel_frame-validate" how="The panel is rebuilt at other sizes from its slices, and a sheet whose bands do not repeat cleanly is refused.">Corner ornaments run into the part that stretches, and they smear when the panel grows.</Guard>
  <Guard node="ui-button_rect-validate" how="All four states are measured against the normal one: the same outline and size, but visibly different.">The pressed button jumps a few pixels, or the hover state looks just like the normal one.</Guard>
  <Guard node="ui-button_rect-validate" how="The gate measures the text area of each surface and records the text colour that reads on it.">Labels are unreadable on the button's face.</Guard>
  <Guard node="ui-preview_icons-validate" how="Each icon is found in its own cell, the set is checked for one size, and nothing may sit outside the cells.">Icons drift off-centre and come out at different sizes.</Guard>
  <Guard node="ui-preview_icons-review" how="A reviewer that did not draw the sheet judges it against the direction and the cover.">The kit slowly drifts away from the game's style.</Guard>
</Guards>
