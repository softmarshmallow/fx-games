Universe

A poster, a synopsis and a direction in. A reviewed storyworld and one concept image per entity out.

universe · Page · Contract

A semantic phase proposes typed entities, their relationships and open questions, which an independent reviewer must admit; a gallery phase then draws exactly one reviewed concept image for each admitted entity.

Steps

StepNode types
Propose and admit the world
The world's entities, facts, relationships and open questions are proposed from the synopsis and direction, with the poster as visual evidence only; deterministic judges hold the proposal and the gallery plan to their rules, an independent review must pass them, and only then is the world admitted.
Number the sources universe/world/source
Reduce the poster universe/world/poster_small
Propose the world universe/world/propose
Check the proposal universe/world/proposal_ok
Project the world for the planner universe/world/projection
Plan the gallery as a set universe/world/plan
Check the plan universe/world/plan_ok
Review the world independently universe/world/review
Admit the world universe/world/admit
Compile the visual grammar
One shared grammar for the whole set, in the medium's own words: silhouettes, architecture, costume, materials, palettes, and the substitutions an image must never make.
Project the world for its grammar universe/look/projection
Compile the grammar universe/look/grammar
Check the grammar universe/look/grammar_ok
Draw each entity
Each admitted entity is directed, drawn fresh with no references, and reviewed against its record. A rejected image stays in the gallery, marked; a new take is drawn only when asked for (a reroll).
Gather the entity's record universe/entity/context
Direct the image universe/entity/direct
Check the direction universe/entity/direct_ok
Write the image instruction universe/entity/brief
Draw the concept image universe/entity/draw
Seal what the reviewer sees universe/entity/sealed
Review the image universe/entity/review
Write the entity's record universe/entity/record
Package the gallery
The admitted world and every entity's image, record and readable page, laid out as one folder beside a manifest of each entity's status and the rights the run was given.
Package the gallery universe/close

Try it

The committed lantern_ferry world in inputs/lantern_ferry: a poster, a synopsis, an expansion direction and the inputs.yaml that names them

uv run python -m grida.fx plan universe --inputs src/fx_games/workflows/universe/inputs/lantern_ferry/inputs.yaml

uv run python -m grida.fx run universe --inputs src/fx_games/workflows/universe/inputs/lantern_ferry/inputs.yaml --live --max-usd 1

uv run python -m grida.fx inspect universe --verify
