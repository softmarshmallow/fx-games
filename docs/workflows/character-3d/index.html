3D character

One written brief in. One rigged, reviewed character out.

character-3d · Page · Contract

An agent draws reference views, a 3D service builds a textured mesh from them, and the mesh is stood upright, rigged and given test clips. Independent reviewers judge every stage on renders in the export's own finish, and the export is admitted only when numbers and pictures both pass.

Steps

StepNode types
Compile the profile
The profile's anatomy, parts, joints, criteria and review heights, with the partition applied, held to the character rules while planning: a profile or partition they refuse stops the plan before anything is paid for.
Compile the profile character_3d/setup
Draw the references
An agent draws a canonical picture of the character and a front and back of every part, and submits them as one bundle; a reviewer that did not draw them judges the bundle. A rejected bundle is drawn again, told what the review found.
Draw the references character_3d/references/draw
Review the references character_3d/references/review
Build the body
Parts, assembly and rig, built once and rebuilt when the assembly or the rig is still rejected after its own takes. Each part is generated by Tripo from its reference views (or taken as supplied), normalized and reviewed; an agent stands the parts up as one character, reviewed at the bar's heights; the skeleton comes from Tripo, finished locally, or from an agent, and is reviewed on a labeled atlas of every pose.
Pick the part's views character_3d/build/part/views
Generate the mesh character_3d/build/part/mesh
Normalize the mesh character_3d/build/part/normalize
Review the part character_3d/build/part/review
Stand the parts up character_3d/build/assembly/assemble
Review the assembly character_3d/build/assembly/review
Rig with Tripo character_3d/build/rig/task
Finish the provider rig character_3d/build/rig/finish
Rig with an agent character_3d/build/rig/agent
Review the rig character_3d/build/rig/review
Admit the character
With reviews, the character is accepted only when its review accepted it and its numbers hold; without, it is delivered unreviewed only when its export is intact. Its findings travel with it.
Admit the character character_3d/result

Outputs

outputs/character.glbThe character: textured mesh, skeleton and short clips, at game scale
outputs/result.jsonAccepted, or delivered unreviewed, with the findings that travel with it
outputs/references.pngThe canonical reference picture the parts were drawn from
outputs/atlas/The labeled pose rows and the face strip the rig reviewer judged

Try it

The committed brief in inputs/sample, an original courier, and the inputs.yaml that names it. The run is paid: it needs OpenRouter and Tripo keys, Blender, and --live

uv run python -m grida.fx plan character-3d --inputs src/fx_games/workflows/character_3d/inputs/sample/inputs.yaml

uv run python -m grida.fx run character-3d --inputs src/fx_games/workflows/character_3d/inputs/sample/inputs.yaml --live --max-usd 30

uv run python -m grida.fx inspect character-3d
